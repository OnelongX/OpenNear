3 分钟真机一镜到底演示脚本（2~3 块 ESP32 即可）

1

一键刷机通电

1 号板刷 TLS 网关，2/3 号板刷 同步演示从机。通电 2 秒后所有板载蓝灯（GPIO2）自动进入严格同拍闪烁。

2

手机连热点看 SVG 拓扑

手机连接 OpenNear-Setup-XXXX，自动弹出 Web 管理台，实时看到所有节点的 MAC 地址、SVG 多跳树、实时遥测载荷，点按钮可给节点改名。

3

一键切换高频同拍灯效

在「节点控制」页点 高频频闪 STROBE 或 心跳同拍 PULSE，多块板（含隔墙 2 跳板）毫秒无差同步切换。

4

现场拔主控电源看热备秒切

直接拔掉 1 号主控 USB，2 号 Backup 节点零投票接管继续带队同拍不断档；忘记配置可长按板载 BOOT 键 5 秒恢复出厂。

也支持本地 PlatformIO 编译烧录

git clone https://github.com/OnelongX/OpenNear.git
cd OpenNear/ports/esp32_wroom32
